# Matematika untuk Data Science

Dokumentasi belajar distribusi probabilitas, klasifikasi Naive Bayes, dan uji hipotesis.

## Sumber

Template berasal dari kelas Dicoding **Belajar Matematika untuk Data Science**.
Instruksi, nama fungsi, dan keluaran acuan mengikuti template yang diberikan.

## Lingkup tahap 1

- Distribusi uniform, Gaussian, dan binomial.
- Pembuatan data sintetis untuk tiga jenis burung.
- PDF, PMF, estimasi parameter, prior, likelihood, dan prediksi Naive Bayes.

## Menjalankan

1. Buka https://colab.research.google.com/.
2. Pilih **File → Upload notebook**, lalu unggah notebook `.ipynb` di repository ini.
3. Simpan salinan ke Google Drive.
4. Baca penjelasan dan jalankan sel sesuai urutan dari atas ke bawah.
5. Setelah seluruh bagian lengkap, jalankan semua sel dan unduh `.ipynb` serta `.py` dari versi yang sama.
